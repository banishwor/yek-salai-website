# Advanced Yek Salai Eligibility Checker

An advanced, culturally-accurate decision-support application designed to review customary marriage suitability under traditional Meitei (Meetei) laws. This tool evaluates exogamy boundaries beyond simple same-Yek (clan) matching, incorporating maternal clan lineages, specific traditional family lineages, and custom proscriptions.

Developed as a modern web application, it respects Meitei heritage and aims to protect ancestral lineage sanctity (_Yek-Salai exogamy_).

**Live Site:** [Open the Yek Salai Eligibility Checker](https://banishwor.github.io/yek-salai-website/)

---

## 🌟 Key Features

Unlike standard converters or basic tools, this platform implements a multi-stage traditional algorithm:

*   **Same Yek (Clan) Exogamy Check**: Automatically identifies overlapping primary clans (Mangang, Luwang, Khuman, Angom, Moirang, Kha-Nganba, Chenglei).
*   **Multi-Yek Surname Resolution**: Supports historical surnames matching multiple clans (e.g., *Laishram*, *Salam*), allowing granular selection.
*   **Maternal Clan Relationship Analysis**: Evaluates maternal lineage constraints to prevent prohibited *Yumnak* crossings.
*   **Shared Maternal Grandmother Assessment**: Checks for closer maternal relatives (within the customary prohibited generation threshold).
*   **Shairuk Tinaba Proscriptions**: Models historical and ancestral sub-lineage restrictions, including:
    *   *Group 1 (Mangang Exceptions)*: Mungyamcham, Lairencham/Lairenjam, Kanghujam boundaries.
    *   *Group 2 (Moirang-Angom Exceptions)*: Moirang Anouba lineage restrictions relative to Angom Salai.
    *   *Group 3 (Inter-Clan Origin Blocs)*: Cross-clan boundaries involving Sarang Leishangthem, Khaba Nganba, Haorok Konthou, and Moirang Ariba.
    *   *Group 4 (Khaba-Angom Exceptions)*: Achom, Yumlembam, Hidam, and Langmaithem limitations.
*   **Digital Image Passport Gen**: Instantly generates a high-fidelity certified Report Card with custom borders and gold/emerald styling, ready to download as a PNG or share on social media platforms (WhatsApp, Telegram, etc.) using native Web Share triggers on mobile device browsers.

## 🚀 Getting Started

### Prerequisites

*   Make sure you have Node.js (version 18 or higher) installed on your system.

### Installation

1. Clone the repository to your local system:
   ```bash
   git clone https://github.com/yourusername/yek-salai-checker.git
   cd yek-salai-checker
   ```

2. Install all required dependencies:
   ```bash
   npm install
   ```

3. Launch the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to:
   ```text
   http://localhost:3000
   ```

### Building for Production

Compile the production-ready build (React single page application) into static HTML/CSS/JS assets inside the `dist/` directory:
```bash
npm run build
```
